# Tripleten web_project_around_es

## Titulo

Proyecto de Sprint 8 Usar conocimientos recien adquiridos de JS y uso de DOM para aplicar interactividad a la pagina "AROUND TH US" en formularios, edicion de perfiles, creacion de publicaciones, etc.

## Autor

Hector Lopez Cuevas

## Descripcion

Usar las distintas funciones, Metodos y Conceptos del DOM para realizar un cambio en la pagina "AROUND THE US" y darle mas interactividad a sus distintas propiedades. Abrir formularios, enviar informacion, editar perfil, crear nuevas publicaciones, etc.

## Tecnologias

- HTML
- JavaScript
- DOM
